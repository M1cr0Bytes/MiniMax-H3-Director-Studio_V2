# Changelog

## Chain execution tracking

- Associate completion events with the submitted prompt ID and ignore events from other executions.
- Keep each Director's virtual controls separate and check the active workflow and clip before queueing.
- Stop automatic chaining if the original workflow is no longer active; return to that tab to resume.
- Validated with simulated queue events; live ComfyUI verification is still needed.

## BASE + FINAL continuity update

- Added a separate Motion Context to the upscale pass, using the preceding FINAL audiovisual latent at the output resolution.
- Kept BASE and FINAL continuity checkpoints separate and trimmed the FINAL context with its corresponding audio.
- Chain checks completed FINAL checkpoints, resumes from the selected pending clip and updates the selector as it advances.
- Clear temporary latents removes the current project's numbered BASE and FINAL checkpoints.
- Existing projects need FINAL checkpoints generated by this version; start from clip 1 or upscale saved BASEs in order. Existing MP4s cannot serve as FINAL context.

## V2 UI hotfix

- Restored internal vertical scrolling; opening prompts no longer auto-resizes the node.
- Restored the Generate clip button beside the BASE/FINAL switch.
- Corrected BASE button selection and clip-selector detection in the V2 interface.

## V2

- Removed the built-in Director live preview panel and placed the optional Kijai BASE preview outside the Director, where it can be enabled or bypassed independently.

- Added a clean public workflow with no personal prompts, references, audio, render history or local output paths.
- Added BASE review flow: render a BASE pass, choose it, then upscale that exact accepted latent.
- Added a direct BASE + Upscale execution path for clips that do not need review.
- Consolidated BASE and Upscale controls for steps, samplers, schedulers, denoise, 3D multiplier and latent-upscaler model selection.
- Preserved segment continuity through the Director/Motion Context workflow.
- Added Spectrum to the included workflow for the **BASE pass only**.
  - Recommended configuration: non-Turbo BASE generation at approximately **25 steps**.
  - Do not use Spectrum with Turbo LoRAs or short Turbo step presets.
  - Spectrum is not used in the Latent 3D Upscale pass.

### Workflow housekeeping

- All workflow nodes are pinned.
- Reference images, reference audio, prompts, Creative Writer history, stored previews and local paths have been removed before publication.
